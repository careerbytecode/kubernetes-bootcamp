10-Day Curriculum

01

Kubernetes Fundamentals

Architecture, control plane & worker nodes, pods, namespaces, and kubectl. Use case: deploy and expose an Nginx app with a ClusterIP service.

02

Objects & YAML

Manifests, labels & selectors, ReplicaSets, Deployments, and desired-state management. Use case: scale a web app from 2 to 4 replicas via YAML.

03

Deployments & Release Strategies

Rollouts & rollbacks, Recreate, Rolling Update, Blue-Green, and zero-downtime concepts. Use case: upgrade v1→v2 with a rolling then blue-green switch.

04

Configuration & Storage

ConfigMaps, Secrets, environment variables, PV/PVC, StorageClasses, stateful vs stateless. Use case: read config from a ConfigMap and Secret, persist data on a PVC.

05

Networking

Pod-to-pod communication, Services (ClusterIP, NodePort, LoadBalancer), DNS, and Network Policies. Use case: connect two apps and block unwanted traffic with a NetworkPolicy.

06

Gateway API

GatewayClass, Gateway, HTTPRoute, host- and path-based routing, external exposure. Use case: route /app1 and /app2 with Gateway API instead of Ingress.

07

Scheduling & Workload Placement

Node & pod affinity and anti-affinity, taints & tolerations, workload isolation. Use case: pin a critical app to dedicated nodes and spread replicas safely.

08

Resource Management & Reliability

Requests & limits, QoS, OOMKilled, readiness/liveness/startup probes, and HPA. Use case: fix an OOMKilled app by tuning limits and probes.

09

CI/CD & GitOps

GitHub Actions CI, container registries, Argo CD, self-healing, and drift detection. Use case: push to GitHub → Actions builds the image → Argo CD syncs it to the cluster.

10

Helm & AI-Powered Ops

Helm charts & values, K8sGPT + Ollama, and troubleshooting labs (CrashLoopBackOff, ImagePullBackOff, OOMKilled). Use case: package with Helm, then debug a broken pod with K8sGPT.

★

Capstone Project

Deploy and stabilize a customer-facing application end to end — using GitHub Actions, Argo CD, Gateway API, Helm, and AI-assisted troubleshooting with K8sGPT.
